Captures de sauvegarde

Une capture = la sauvegarde du jeu à un instant donné. Faites-en une, jouez et accomplissez quelque chose de précis (gagner des pièces, finir un niveau…), puis refaites-en une. Au moins 2 captures, idéalement 3–5.

＋ Ajouter une capture fichiers de la save ou .zip (JKSV)
Comment récupérer les captures sans PC
  1. Sur la Switch : ouvrez JKSV, choisissez le jeu → votre profil → Nouvelle sauvegarde. Donnez un nom parlant (ex. avant-boss). JKSV l'écrit dans sdmc:/JKSV/<jeu>/.
  2. Vers le téléphone, au choix :
    • ftpd (homebrew) sur la Switch + une appli FTP sur le téléphone (ex. une appli de gestion de fichiers qui gère le FTP) : copiez le dossier de la capture.
    • Le téléversement Google Drive / WebDAV de JKSV, si vous l'avez configuré.
    • La carte SD dans un lecteur USB‑C branché au téléphone.
  3. Ici : Ajouter une capture et sélectionnez tous les fichiers du dossier (ou le .zip JKSV). Répétez pour chaque capture, dans l'ordre chronologique.
  4. Le plus rapide : une capture d'une partie neuve + une save 100 % téléchargée (fil « Switch Save site / 100% Completed Saves » de GBAtemp, etc.), puis « ⚡ Générer les succès » dans l'onglet 3 : toutes les collections et compteurs ressortent d'un coup. Ajoutez une ou deux captures intermédiaires de votre propre partie pour confirmer.
  5. Astuce : faites deux captures sans rien faire entre les deux et cochez « contrôle » sur la seconde. Tout ce qui change quand même (horloge, position…) sera écarté comme bruit.

Rien n'est envoyé sur Internet : les fichiers restent dans votre navigateur.

Chercher une valeur connue

Vous connaissez un chiffre affiché dans le jeu (pièces, rubis, victoires…) ? Notez-le pour chaque capture : l'outil trouve où il est stocké. Laissez vide si vous ne le connaissez pas.

Importer un JSON

Succès

Sous chaque succès : sa valeur dans chaque capture, calculée exactement comme sur la console (✓ = débloqué).

Exporter

Placez le fichier dans sdmc:/switch/SwitchAchievements/games/ sous le nom TITLEID.json, puis relancez l'app et appuyez sur Y. Il remplace la définition intégrée du même jeu : partez des succès intégrés pour ne pas les perdre.
